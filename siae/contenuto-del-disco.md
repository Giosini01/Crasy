## File presenti sul supporto

### `crasy-codice-sorgente.zip` — 7,8 MB, 595 file

Il codice sorgente completo del programma, nella revisione
`1609bd43b9e685661b80938b425d45e06e69137f`.

Struttura principale dell'archivio:

| Cartella | Contenuto |
|---|---|
| `lib/` | Il programma: interfaccia, logica, accesso ai dati (Dart) |
| `functions/` | I componenti eseguiti su server (JavaScript, Node.js) |
| `test/` | Le verifiche automatiche del programma |
| `android/`, `ios/`, `web/` | Configurazione per le tre piattaforme |
| `tool/` | Strumenti di servizio usati dallo sviluppo |
| `assets/` | Immagini e risorse incluse nel programma |

L'archivio contiene i soli file sorgente del progetto. Non comprende le
librerie di terze parti, che non sono opera del depositante e sono scaricate
automaticamente in fase di compilazione dai rispettivi archivi pubblici, ne' i
prodotti intermedi della compilazione.

Non comprende inoltre le chiavi crittografiche e le credenziali di accesso ai
servizi, che non costituiscono codice del programma.
